# OpenCart Manual Testing Project

## 📌 Project Overview

This project focuses on practicing **Manual Software Testing** on a locally hosted OpenCart e-commerce application. The objective was to understand the software testing lifecycle, write test cases, execute test scenarios, document defects, and maintain testing evidence.

## 🎯 Project Objectives

* Understand the fundamentals of manual software testing.
* Create and organize test cases for different application modules.
* Execute test cases and record actual results.
* Identify and document observed defects.
* Capture screenshots as supporting evidence for bug reports.
* Maintain structured testing documentation using Microsoft Excel.

## 🧪 Modules Covered

The following modules were included in the testing practice:

* User Registration
* Login
* Forgot Password
* Product Search
* Shopping Cart
* Checkout
* My Account
* Product Categories

## 🛠️ Tools and Technologies

* **Application Under Test:** OpenCart
* **Local Server Environment:** XAMPP
* **Database:** MySQL
* **Browser:** Google Chrome
* **Documentation:** Microsoft Excel
* **Version Control:** Git and GitHub

## 📂 Project Structure

* **Test-Cases/** — Test cases prepared for the application modules.
* **Test-Execution/** — Test execution records and results.
* **Bug-Reports/** — Bug report documentation and supporting screenshots.
* **Bug-Reports/Screenshots/** — Evidence screenshots organized into folders.
* **Environment-Setup/** — Screenshots related to the local testing environment, if included.

## 🔍 Testing Activities

1. Explored the OpenCart application and its major features.
2. Prepared test cases with relevant test steps and expected results.
3. Executed test cases and recorded actual results.
4. Documented observed defects with relevant details.
5. Captured screenshots to support bug reports.
6. Organized project documents and evidence in GitHub.
