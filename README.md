# OpenCart Manual Testing Project

## About the Project

This is a self-practice manual testing project performed on a locally installed OpenCart e-commerce website.

## Testing Modules

* Registration
* Login
* Forgot Password
* Search
* Shopping Cart
* Checkout
* My Account
* Product Categories

## Tools Used

* OpenCart
* XAMPP
* Microsoft Excel
* Google Chrome
* GitHub

## Project Documents

* Test Cases
* Test Execution
* Bug Reports
* Testing Evidence Screenshots

## Testing Activities

* Created test cases for different modules.
* Executed test cases and recorded actual results.
* Prepared bug reports for observed issues.
* Captured screenshots as testing evidence.

## Project Type

Personal learning project for practising manual software testing.
